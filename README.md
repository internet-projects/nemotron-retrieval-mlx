# Nemotron 3.5 retrieval on Apple Silicon (MLX)

MLX port of NVIDIA's Nemotron 3.5 retrieval models for text: [Nemotron-3.5-Embed-1B](https://huggingface.co/nvidia/Nemotron-3.5-Embed-1B-BF16),
[Nemotron-3.5-Embed-8B](https://huggingface.co/nvidia/Nemotron-3.5-Embed-8B-BF16) and
[Nemotron-3.5-Rerank-8B](https://huggingface.co/nvidia/Nemotron-3.5-Rerank-8B-BF16). Not affiliated with NVIDIA.
(Work in progress: results and usage are filled in after the checks.)
